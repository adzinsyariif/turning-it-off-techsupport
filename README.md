One funny line a hopeless tech support agent gives a desperate customer — cheerfully useless advice that twists the classic "turn it off and on again" into a permanent fix.

> Great news — turn it off and never back on, and it will never error again!

## Run

```bash
python3 main.py
```

Writes the line to `/output/entry.txt` as UTF-8 with no trailing newline.
